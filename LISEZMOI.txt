BELMONT PRACTICE {VERSION}
Mod d'entraînement pour Castlevania: Belmont's Curse (version Steam, Windows)
==========================================================================

Savestates, retour sur les boss, téléportation depuis la carte, accélération
des cinématiques, PV / mana / potions infinis, noclip...


AVANT D'INSTALLER : SAUVEGARDE TES PARTIES
------------------------------------------
Le mod écrit dans la sauvegarde du jeu (chargement de savestates, bouton Fight).
Copie d'abord le dossier de tes sauvegardes dans un endroit sûr :

  %USERPROFILE%\AppData\LocalLow\KONAMI\Castlevania Belmont's Curse

(colle ce chemin dans la barre d'adresse de l'Explorateur Windows)

Le mod fait aussi une copie de tes sauvegardes à chaque lancement du jeu,
dans <dossier du jeu>\BelmontPractice\SauvegardesJeu (les 10 dernières).


VERSION DU JEU : 1.1.3
----------------------
Le mod est fait pour la version 1.1.3 du jeu (patch du 16/10/2026). Steam
installe toujours la dernière version, qui peut casser le mod : on télécharge
donc la 1.1.3 dans un dossier à part. Ton install Steam normale n'est pas
touchée et continue de se mettre à jour.

Attention : les deux versions utilisent le MÊME dossier de sauvegardes
(voir plus haut). Une partie enregistrée avec une version plus récente risque
de ne pas se charger correctement en 1.1.3 : garde ta copie de sauvegarde.


1. TÉLÉCHARGER LA VERSION 1.1.3 (une seule fois)
------------------------------------------------
Il faut posséder le jeu sur le compte Steam connecté.

  a. Lance Steam. Dans la barre d'adresse de ton navigateur, tape :

       steam://open/console

     et accepte d'ouvrir Steam : l'onglet "Console" apparaît dans Steam.

  b. Dans la console Steam, colle cette commande puis Entrée :

       download_depot 4231820 4231821 8796979530797619124

     (4231820 = le jeu, 4231821 = ses fichiers, le dernier nombre = la
     version 1.1.3). Il n'y a pas de barre de progression : attends le
     message "Depot download complete" (environ 6 Go).

  c. Les fichiers arrivent dans :

       C:\Program Files (x86)\Steam\steamapps\content\app_4231820\depot_4231821

     Déplace ce dossier où tu veux et renomme-le, par exemple :

       C:\Games\Castlevania Belmont's Curse (Modded)

     C'est ton "dossier du jeu" pour la suite.


2. CRÉER LE FICHIER steam_appid.txt
-----------------------------------
Hors du dossier Steam, le jeu a besoin de ce fichier pour se lancer.

  a. Dans le dossier du jeu (à côté de "Castlevania Belmont's Curse.exe"),
     crée un fichier texte nommé exactement :

       steam_appid.txt

     (attention à ne pas obtenir "steam_appid.txt.txt" : dans l'Explorateur,
     active Affichage > Afficher > Extensions de noms de fichiers).

  b. Mets dedans uniquement ce nombre, sans espace ni ligne vide :

       4231820

  c. Pour jouer à cette version, lance "Castlevania Belmont's Curse.exe"
     directement (Steam doit être ouvert et connecté). Ne passe pas par le
     bouton Jouer de Steam, qui lance l'autre install.


3. INSTALLER BEPINEX (une seule fois)
-------------------------------------
Il faut EXACTEMENT cette version de BepInEx :

  BepInEx 6.0.0-be.791, variante Unity IL2CPP, Windows x64

  - Page des builds : https://builds.bepinex.dev/projects/bepinex_be
  - Choisis la build #791 (commit b782da4), puis le fichier dont le nom
    commence par "BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.791"

Le BepInEx 5 "stable" ne marche pas avec ce jeu, et une autre build 6.0.0-be
risque de ne pas charger le mod.

  a. Décompresse le zip de BepInEx dans le dossier du jeu de l'étape 1
     (winhttp.dll doit se retrouver à côté de l'exécutable du jeu).
  b. Lance le jeu (l'exe, voir 2c) et attends le menu principal : BepInEx
     prépare les fichiers du jeu, ça prend 1 à 2 minutes la première fois.
     Une fenêtre de console BepInEx peut s'ouvrir : c'est normal.
  c. Quitte le jeu.


4. INSTALLER LE MOD
-------------------
Décompresse BelmontPractice-{VERSION}.zip dans le dossier du jeu (le même que
pour BepInEx), en acceptant de fusionner les dossiers. Tu dois obtenir :

  <dossier du jeu>\BepInEx\plugins\BelmontPractice\BelmontPractice.dll
  <dossier du jeu>\BepInEx\plugins\BelmontPractice\icons\...

Lance le jeu et charge une partie. La version du mod et celle du jeu sont
affichées en haut à droite du menu principal.


5. UTILISATION
--------------
  F1            ouvre / ferme les fenêtres du mod
  F5 / F6       sauver / charger le quickslot (aussi pavé numérique 7 / 8)
  Pavé num. 9   sauver dans un emplacement (puis un chiffre 0-9)
  Pavé num. 3   charger un emplacement (puis un chiffre 0-9)
  Pavé num. 4/6 page de savestates précédente / suivante
  F7 (manette Y) accélérer les cinématiques
  T             carte ouverte : se téléporter au point sous le curseur

Dans le panneau latéral (F1) :
  General   PV / mana / potions infinis, noclip, améliorations...
  Skills    capacités et arcanes
  Items     armes, reliques et équipements
  Bosses    remettre un boss en vie et le refaire (bouton Fight)
  Keybinds  options On / Off et tous les raccourcis (clic sur un raccourci,
            puis appuie sur la nouvelle touche)

Dans la fenêtre des savestates : double-clic sur un nom pour le charger,
crayon pour renommer, poubelle pour supprimer.

Les savestates sont dans <dossier du jeu>\BelmontPractice\Savestates.
Les réglages sont dans <dossier du jeu>\BepInEx\config\fr.vasseur.belmontpractice.cfg.


EN CAS DE PROBLÈME
------------------
- Le journal du jeu est dans <dossier du jeu>\BepInEx\LogOutput.log :
  envoie-le avec une description de ce que tu faisais.
- Si le mod ne se charge pas, vérifie dans ce journal la ligne
  "BepInEx 6.0.0-be.791" tout en haut. Le mod y signale aussi une autre
  version de BepInEx.
- Une mise à jour du jeu peut casser le mod jusqu'à la version suivante.
- Pour désinstaller : supprime le dossier BepInEx\plugins\BelmontPractice
  (ou winhttp.dll pour désactiver BepInEx entièrement).
- Certains antivirus se méfient de winhttp.dll (le lanceur de BepInEx) :
  c'est normal pour un chargeur de mods.
